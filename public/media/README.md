# Vídeo do hero

Coloque aqui o vídeo de fundo da página inicial com o nome **`hero.mp4`**
(`public/media/hero.mp4`).

Recomendado: MP4 (H.264), até ~10–15s em loop, mudo, orientação paisagem,
1080p ou mais. Mantenha o arquivo leve (idealmente < 8 MB) para carregar rápido.

Enquanto o vídeo não estiver presente, o hero exibe automaticamente um shader
animado (LiquidChrome) como plano de fundo — então a página nunca fica vazia.
